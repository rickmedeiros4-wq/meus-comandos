# 🚀 Meu Manual de Bolso - Dev Linux & Git

Guia prático de comandos para o dia a dia.

## 📁 Navegação (Linux)
- `mkdir nome-da-pasta` -> Cria uma pasta.
- `cd nome-da-pasta` -> Entra na pasta.
- `code .` -> Abre a pasta atual no VS Code.

## 🐙 Git & GitHub
- `git clone URL` -> Baixa um projeto do GitHub.
- `git status` -> Mostra o que foi alterado no código.
- `git add .` -> Prepara as alterações para salvar.
- `git commit -m "mensagem"` -> Salva as alterações localmente.
- `git push` -> Envia as alterações para o site do GitHub.

## 🟢 Node.js & Docker
- `npm install` -> Baixa as dependências do projeto.
- `npm run dev` -> Sobe o banco no Docker e roda o site localmente.


## 🐧 Comandos Essenciais do Terminal (Linux / WSL)
- `ls` -> Mostra arquivos e pastas do local atual.
- `pwd` -> Mostra o caminho completo da pasta atual.
- `cd ..` -> Volta para a pasta anterior.
- `clear` -> Limpa a tela do terminal.

## 🐙 Comandos Avançados do Git
- `git status` -> Mostra quais arquivos foram modificados.
- `git diff` -> Mostra linha por linha o que foi alterado.
- `git log` -> Mostra o histórico de todos os commits.

## 📦 Comandos do Ecossistema Node.js (NPM)
- `npm run dev` -> Roda o projeto em modo de desenvolvimento.
- `npm run test` -> Executa os testes automatizados do projeto.

## 🐋 Comandos Básicos do Docker
- `docker ps` -> Lista os containers que estão rodando agora.
- `docker logs nome` -> Mostra o que está acontecendo no container.
