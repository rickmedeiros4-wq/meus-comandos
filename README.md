# 🚀 Meu Manual de Bolso - Dev Linux & Git

Guia prático de comandos para o dia a dia.

## 📁 Navegação (Linux)
- `mkdir nome-da-pasta` -> Cria uma pasta.
- `cd nome-da-pasta` -> Entra na pasta.
- `code .` -> Abre a pasta atual no VS Code.

## 🐙 Git & GitHub
- `git clone URL` -> Baixa um projeto do GitHub.
- `git status` -> Mostra o que foi alterado no código.
- `git add .` -> Prepara as alterações para salvar.
- `git commit -m "mensagem"` -> Salva as alterações localmente.
- `git push` -> Envia as alterações para o site do GitHub.

## 🟢 Node.js & Docker
- `npm install` -> Baixa as dependências do projeto.
- `npm run dev` -> Sobe o banco no Docker e roda o site localmente.
